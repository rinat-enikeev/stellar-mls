Onym is a private group messaging app built on Stellar MLS (Messaging Layer Security). It uses zero-knowledge proofs for anonymous group membership verification, end-to-end encryption for all messages, and decentralized message transport over Nostr relays.

Features:
- End-to-end encrypted group chat with forward secrecy
- Zero-knowledge proof based group membership (no server knows who is in which group)
- Voice and video calls via WebRTC
- Decentralized push notifications via UnifiedPush
- QR code based group invitations
- On-chain group state verification via Soroban smart contracts
- Encrypted media sharing via Blossom servers
- No phone number or email required
