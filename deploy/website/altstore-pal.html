Install Onym via AltStore PAL

Onym Chat is distributed through AltStore PAL — Apple's official alternative marketplace for iPhones in the European Union. Every build is reviewed and notarized by Apple.

Open in AltStore PAL
Source URL
https://onym.chat/altstore-source.json

Manual install (if the button above doesn't open)

  1. Install AltStore PAL on your iPhone (EU only — requires iOS 17.4+).
  2. Open AltStore PAL and go to the Sources tab.
  3. Tap the + button in the top-right and paste the source URL above.
  4. Open the new Onym Chat source and tap Get to install.
Outside the EU? AltStore PAL is only available on iPhones registered to an EU country. Use the TestFlight beta on the home page instead.
