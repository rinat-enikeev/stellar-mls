# Companion piece for Protocolized

This directory holds a thinkpiece-style companion to the SoK,
intended for submission to **Protocolized** (https://protocolized.io)
— the Protocol Institute's sci-fi-and-thinkpiece magazine that grew
out of the Summer of Protocols program.

The companion is **separate from** the SoK in `..` because the two
serve different audiences. The SoK is dense academic prose targeted
at IEEE S&P / USENIX / CCS / FC reviewers. Protocolized's audience
mixes researchers, practitioners, academics, and corporate partners,
and the house style blends speculative fiction with policy analysis.
Trying to bind both into one document creates tonal inconsistency
that hurts both.

## Files

- `who-pays-for-the-garden-wall.md` — the main piece. Lightly
  speculative — opens with a near-future scenario, then sober
  analysis of three incentive-model families (pay-per-action,
  relayer + sponsor, dues + treasury) for SNARK-gated community
  venues, using the SoK's six-axis taxonomy as analytical
  scaffolding.

## Voice

Clear-eyed, jargon-explained, ~2,000 words. Uses Markdown
(Protocolized's Substack supports it). The speculative frame is
"fiction-as-motivation," not "fiction-as-content" — the scenario
serves to anchor the analysis, then steps aside.

## Relationship to the SoK

The piece cites the SoK for technical depth; readers wanting
benchmark numbers, the full configuration catalogue, or the
migration matrix should follow that pointer. The companion stands
on its own for readers whose interest is the economic shape of the
problem class.
