% epoch, parameters); admits state changes that hide the actor and

%   - Active adversary may submit forged proofs (defended by SNARK
%     soundness).
%   - Honest-but-curious validators / RPC operators (defended by

%   - Passive network observer (defended by commitment hiding +
%     fee-payer / submission-pattern obfuscation, separate from the
%     SNARK itself).
%   - Compromised setup contributor (per-circuit Groth16): explicitly
%     in scope; out-of-scope assumptions are flagged.
%
% Properties to formalize:
%   - Soundness — only valid transitions are accepted.
%   - Privacy — actor/membership not revealed beyond the registry's
%     public state.
%   - Liveness — honest member can always advance state when the
%     authorization rule permits.
%
